# LecturerManager

## Użytkownicy oprogramowania

- nauczyciel akademicki (ja)
- studenci


## Cele projektu

- usprawnienie wysyłania wyników zadań przez studentów
- usprawnienie sprawdzania zadań przez nauczyciela
- usprawnienie zapisywania się na listę obecności


## Funkcjonalności

### Wysyłanie zadań

Student kolejno:
  - wybiera zajęcia
  - wybiera konkretne zadanie
  - wypełnia elementy zadania do sprawdzenia
  - naciska przycisk wyślij
  - student wie czy zadanie zostało wysłane poprawnie

Elementami zadania do sprawdzenia może być np. zrzut ekranu, odpowiedź tekstowa.


### Sprawdzanie zadań

Nauczyciel kolejno:
  - wybiera zajęcia
  - wybiera konkretne zadanie
  - wybiera element zadania do sprawdzenia
  - nauczyciel widzi wysłany element zadania do sprawdzenia przez studenta 1
  - nauczyciel naciska przycisk cyfry na klawiaturze (punkty jakie student dostał za ten element)
  - system zapisuje ile student 1 dostał punktów za ten element
  - nauczyciel widzi wysłany element zadania do sprawdzenia przez studenta 2 
  - nauczyciel naciska przycisk cyfry na klawiaturze (punkty jakie student dostał za ten element)
  - system zapisuje ile student 2 dostał punktów za ten element
  - ...
  - gdy nie będzie więcej wysłanych tego typu elementów zadania, nauczyciel widzi informacje, że sprawdził dla wszystkich studentów dany element zadania
  - nauczyciel może wybrać kolejny element zadania


### Dodawanie zajęć

Nauczyciel może dodawać zajęcia.


### Dodawanie zadań

Nauczyciel może dodawać zadania do danych zajęć.


### Dodawanie elementów zadań

Nauczyciel może dodawać do zadania elementy zadania jakie później będzie musiał uzupełnić student.


### Wpisywanie się na listę obecności

Opis zostanie dodany w przyszłości
